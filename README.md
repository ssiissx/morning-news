# 아침 뉴스

매일 오전 7시(한국 시간)에 여러 언론사의 RSS를 모아, 같은 사건을 다룬 기사끼리 묶고 많이 보도된 순서로 정리한 페이지를 만듭니다.

- 보는 곳: https://ssiissx.github.io/morning-news/
- 지난 30일치는 `archive/` 에 날짜별로 남습니다.
- GitHub Actions(공개 저장소라 무료)가 실행하므로 PC가 꺼져 있어도, Claude 없이도 돌아갑니다.

## 구성

| 파일 | 하는 일 |
| --- | --- |
| `scripts/feeds.json` | 출처 목록과 섹션. 여기만 고치면 출처를 더하거나 뺄 수 있어요 |
| `scripts/build_news.py` | 기사를 모아 묶고 `index.html` 을 만드는 프로그램 (파이썬 표준 라이브러리만 사용) |
| `.github/workflows/news.yml` | 매일 실행 일정과 배포 |

## 자주 하는 일

**출처 더하기·빼기**: `scripts/feeds.json` 의 `feeds` 배열에 한 줄을 넣거나 지웁니다. GitHub 웹에서 파일을 열고 연필 아이콘으로 고친 뒤 저장하면, 저장하는 순간 다시 만들어집니다.

```json
{"name": "언론사 이름", "lang": "ko", "url": "https://.../rss.xml"}
```

- `lang`: `ko` 한국어, `en` 영어, `ja` 일본어
- `match` / `exclude`: 제목에 이 단어가 있을 때만 넣기 / 빼기 (예: `"exclude": "날씨|한파"`)
- 섹션의 `hours`: 몇 시간 안의 기사까지 볼지, `limits`: 언어별로 몇 개까지 보여줄지

**시간 바꾸기**: `news.yml` 의 `cron: "0 22 * * *"` 는 세계 표준시 22시 = 한국 오전 7시입니다. 한국 시간에서 9시간을 빼서 적으면 됩니다 (오전 6시 → `"0 21 * * *"`).

**지금 바로 만들기**: 저장소의 Actions 탭 → 아침 뉴스 → Run workflow.

**내 PC에서 만들어 보기**: `python scripts/build_news.py` 를 실행하면 `index.html` 이 생깁니다.

## 멈췄을 때

- Actions 탭에 빨간 표시가 있으면 눌러서 어느 단계가 실패했는지 봅니다. 출처가 5곳 미만으로만 받아지면 일부러 페이지를 바꾸지 않고 실패로 끝납니다(인터넷 문제일 때가 많아요). 다음 날 저절로 다시 돕니다.
- 어떤 출처가 계속 안 받아지면 페이지 맨 아래 ‘오늘 못 받은 곳’에 줄을 그어 표시합니다. 주소가 바뀐 것이니 `feeds.json` 에서 고치거나 지우세요.
- GitHub는 오래 아무 변화가 없는 저장소의 예약 실행을 멈추는데, 이 저장소는 매일 기록을 커밋하므로 보통 멈추지 않습니다. 혹시 멈추면 Actions 탭에서 ‘Enable workflow’를 누르세요.
